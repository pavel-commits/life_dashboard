# Личный дашборд

Локальное приложение на Streamlit для задач, привычек и заметок. Данные
хранятся в SQLite рядом с кодом приложения.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

После запуска приложение доступно по адресу `http://localhost:8501`.

## Возможности

- Просмотр блоков «Задачи», «Привычки» и «Заметки».
- Dashboard с задачами на сегодня, недельной статистикой, активными привычками и streak.
- Верхнее меню с разделами «Дашборд», «Задачи», «Цели», «Привычки», «Заметки» и «О себе».
- Создание целей с описанием, датой создания, дедлайном и статусом.
- Связывание существующих задач с целями и автоматический расчёт прогресса.
- Просмотр активных целей и связанных задач на отдельной странице.
- Добавление задачи с названием, описанием, приоритетом, сроком и статусом.
- Редактирование и удаление задач.
- Добавление и удаление привычек.
- Добавление и удаление заметок.
- Тесты запускаются командой `python3 -m unittest discover`.
- Фильтрация задач по категории и приоритету.
- Локальное хранение данных в файле `life_dashboard.db`.

## Структура

- `app.py` — интерфейс Streamlit и обработчики действий.
- `database.py` — подключение к SQLite, миграция схемы и запросы dashboard.
- `models.py` — модели предметной области.
- `requirements.txt` — зависимости Python.
